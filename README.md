# 🎮 Xbox Cloud Toolkit

### Advanced Xbox Cloud Gaming Toolkit for Tampermonkey

Keyboard & Mouse • Virtual Xbox Controller • WebRTC Statistics • Gaming HUD • Auto Game Detection • Profiles

![Version](https://img.shields.io/badge/version-v2.1.1-green)
![Platform](https://img.shields.io/badge/platform-Xbox%20Cloud%20Gaming-107C10)
![License](https://img.shields.io/badge/license-MIT-blue)

</div>

---

## ✨ Features

- 🎮 Keyboard & Mouse Support
- 🎯 Virtual Xbox Controller
- 📊 Real-time WebRTC Statistics
- 📈 RTT / Jitter / Bitrate Graphs
- 🟢 Connection Score System
- 🕹 Automatic Game Detection
- ⚙ Automatic Game Profiles
- 📸 Screenshot Support
- ⏱ Playtime Tracking
- 🎨 Image Enhancement Filters

---

## 🚀 Installation

1. Install Tampermonkey
2. Download `xcloud-toolkit.user.js`
3. Open Xbox Cloud Gaming
4. Enjoy

---

## ⌨ Shortcuts

| Shortcut | Action |
|-----------|----------|
| Alt + G | HUD |
| Alt + V | Toolkit Panel |
| Alt + K | Keyboard + Mouse |
| Alt + S | Statistics |
| Alt + P | Screenshot |
| Alt + F | Fullscreen |
