### Advanced Xbox Cloud Gaming Toolkit for Tampermonkey

Keyboard & Mouse • Virtual Xbox Controller • Smart Profiles • Real-Time HUD • WebRTC Analytics

## ✨ Features

- 🎯 Keyboard & Mouse support with virtual Xbox controller
- 📊 Real-time WebRTC statistics and network diagnostics
- 📈 Live RTT, Jitter and Bitrate graphs
- 🟢 Connection Score system
- 🎮 Automatic Game Detection
- ⚙️ Automatic Profile Switching
- 🖼️ Image Enhancement Filters
- 📸 Screenshot Support
- ⏱️ Playtime Tracking
- 🧩 Profile Manager

## ⌨️ Shortcuts

| Shortcut | Action |
|-----------|----------|
| Alt + G | Toggle HUD |
| Alt + V | Toggle Toolkit Panel |
| Alt + K | Enable / Disable Keyboard & Mouse |
| Alt + S | Toggle Statistics |
| Alt + P | Screenshot |
| Alt + F | Fullscreen |
| Alt + J | Profile Manager |
